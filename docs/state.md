# State

位于 `src/state` 目录下。

所有子组件共享，对外提供了 `useXXXState` 以及对应的 `dispatch`

## AppState

- `AppStateProvider`
- `useAppState`
- `useAppDispatch`

## QueryState

- `QueryStateProvider`
- `useQueryState`
- `useQueryDispatch`

## TimeState

- `TimeStateProvider`
- `useTimeState`
- `useTimeDispatch`

## LogsState

- `LogsStateProvider`
- `useLogsState`
- `useLogsDispatch`

## OverviewState

- `OverviewStateProvider`
- `useOverviewState`
- `useOverviewDispatch`
